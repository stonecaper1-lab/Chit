# Chit

A tiny, free, open-source notes app for Android. Your thoughts stay on your device; Chit minds its own business.

- No ads, trackers, or analytics
- Notes stay on your device and export as plain Markdown
- Optional update check is off by default
- Supports checklists and Markdown
